# Контент игры (данные)

Здесь лежит весь контент среза: точки обзора, зоны, предметы, реплики, значения головоломок.
Эти файлы правят сценарист и левел-дизайнер; программист не нужен.

После правки:
- `python3 game/tools/data_build.py` — проверка и конвертация YAML → `game/content/game_data.json`
  (она же запускается в `game/tools/build_apk.sh` и `game/tools/run_tests.sh`).
- Ошибки (нет реплики, неизвестная зона, тупик в графе, совпадающие коды) печатаются списком, сборка останавливается.

Формат — `docs/levels/slice-01-spec.md`, раздел 8. Отличия и дополнения движка помечены
в файлах комментарием `# engine:`.

Углы: `yaw` 0° — «вперёд» (вход в точку), растёт по часовой стрелке (90° — вправо), 0…360.
`pitch` — вверх положительный, ±90. `size_deg` — угловой диаметр зоны касания.
Панорама — эквидистантная развёртка 2:1, центр картинки = yaw 0°, левый край = yaw 180°.
